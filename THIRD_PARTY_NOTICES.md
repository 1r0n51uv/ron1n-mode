# Componenti riutilizzati

L'icona dell'app, lo script Inno Setup e il file di riconoscimento dell'installazione provengono da [1r0n51uv/consolemode](https://github.com/1r0n51uv/consolemode), derivato da [lippdev/consolemode](https://github.com/lippdev/consolemode). Il codice e la licenza del progetto di provenienza sono indicati nei rispettivi repository. Il file LICENSE conserva la licenza AGPL-3.0.

Le risorse Glass e i template WinUI dei pulsanti, delle card e delle righe delle impostazioni sono adattati dal fork Console Mode (AGPL-3.0). Il font Inter Variable proviene dallo stesso fork ed è distribuito con la [SIL Open Font License](src/Ron1n.Mode/Assets/Fonts/Inter-OFL.txt).

Il programma usa WinUI 3, Windows App SDK e le API di Windows per l’input. Testi e immagini delle schede provengono dal [LaunchBox Games Database](https://gamesdb.launchbox-app.com/).
