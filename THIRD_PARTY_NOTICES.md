# Componenti riutilizzati

L'icona dell'app, lo script Inno Setup e il file di riconoscimento dell'installazione provengono da [1r0n51uv/consolemode](https://github.com/1r0n51uv/consolemode), derivato da [lippdev/consolemode](https://github.com/lippdev/consolemode). Il codice e la licenza del progetto di provenienza sono indicati nei rispettivi repository. Il file LICENSE conserva la licenza AGPL-3.0.

Il programma usa WinUI 3, Windows App SDK e le API di Windows per l’input. Testi e immagini dei giochi vengono recuperati dal client da Steam e Wikipedia. La scheda indica la pagina di Wikipedia quando è la fonte utilizzata. Il repository contiene soltanto l'icona dell'app.
